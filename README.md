# Global Trade Navigator

I'm working as a broker in various commodities, and when I work with various sellers or buyers of commodities like gold, Aluminium, bauxite ore, iron ore, and chemicals and other items that are traded internationally. I get confused about whom to talk to and how to execute the process according to the required procedure. So I need you to work on this problem. If you want anything, you can ask me. Please try to build a little bit of 3D website with a theme of international deals and freight.
